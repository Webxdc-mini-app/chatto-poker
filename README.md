# ちゃっとポーカー 1.1.3

`chatto-poker-1.1.3.xdc` は、DeltaChatのチャットで遊べるテキサスホールデム・ポーカーアプリです。2〜6人の通信対戦と、あなた＋CPU3人の練習対戦に対応しています。

## 主な機能

- 2〜6人の通信対戦
- CPU3人との練習対戦
- 役の自動判定とチップの自動配当
- オールインとサイドポットへの対応
- 推定勝率の表示
- アプリ内で読み返せるゲームルール

## 使い始める

1. `chatto-poker-1.1.3.xdc` をDeltaChatのチャットに送ります。
2. 送った添付アプリを開きます。
3. ホーム画面で「CPU対戦」または「マルチ募集」を選びます。

DeltaChatの添付を開く操作や表示は、端末によって異なります。

## CPUと練習する

1. 「CPU対戦」を押します。
2. 「遊び方」の概要を読み、「開始する」を押します。
3. 自分の番になったら、画面下のボタンで行動します。
4. 結果が表示されたら、自分で「次のハンド」を押します。

## 友だちと通信対戦する

1. 全員が、同じチャットの**同じ添付アプリ**を開きます。
2. 全員が「マルチ募集」を押します。
3. ロビーに参加する全員の名前が表示されるまで待ちます。
4. 「ホスト（開始担当）」と表示された人が「ゲーム開始」を押します。
5. 各自の順番で操作します。
6. 結果が表示されたら、ホストが「次のハンド」を押します。

ホストは参加者IDの順番で決まります。最初に開いた人とは限りません。開始には2〜6人が必要です。名前が揃わない場合は、同じ添付を開いているか確認し、必要に応じて「参加を再通知」を押してください。

## 基本ルールと操作

最初の持ちチップは1人5,000です。SBは50、BBは100を自動で賭けます。手札2枚と共通カード5枚から最も強い5枚を作り、勝った人がポットを獲得します。ほかの全員が降りた場合も勝ちです。

| 操作 | 内容 |
|---|---|
| チェック | 追加で賭けずに次の人へ回します。未払いがないときに選べます。 |
| コール | 現在のベット額に揃えます。チップが足りない場合は残り全額を賭けます。 |
| レイズ | スライダーで追加支払額を設定し、現在のベット額を引き上げます。 |
| フォールド | そのハンドを降ります。すでに賭けた分は戻りません。 |
| オールイン | 残りのチップをすべて賭けます。 |

レイズのスライダーは、支払い合計ではなく**今回追加で払うチップ数**です。例えば、すでに50を払っていて合計200へレイズする場合、追加支払額は150です。

詳しい役の強さや配当方法は、画面上部の「ゲームルール」で確認できます。「推定勝率」はランダムな相手の手札を仮定した目安で、勝利を保証するものではありません。

## 対局の終了と遊び直し

チップ0の人は次のハンドから観戦になり、最後の1人が残ると対局終了です。対局開始後に参加した人も観戦になります。

最初から募集し直す場合は、アプリを**新しい添付**として送り、全員がその新しい添付を開いてください。「ロビーに戻る」は、対局をリセットする操作ではありません。

## 通信対戦の注意点

- ホストはアプリを開いたままにしてください。閉じている間は進行を待ちます。開き直すと、未処理の操作要求を処理します。
- 送信後は通信の反映を待ち、ボタンを連打しないでください。
- 閉じた参加者の自動退出、ホストの自動交代、強制フォールドはありません。
- 旧版との通信互換性はありません。全員が同じバージョンの添付を使ってください。
- 通常画面では相手の手札を隠しますが、データ解析や改造による閲覧・不正を防ぐ方式ではありません。信頼できる相手とのカジュアルな対戦用です。

## 確認状況

ルールの自動テスト15項目、ランダム対局1,200ハンド、模擬通信、実ブラウザの画面操作を確認しています。実際のDeltaChatを搭載した複数端末間の配送・バックグラウンド動作は、この環境では未検証です。
